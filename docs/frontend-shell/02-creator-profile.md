# Creator Profile

## Goal

Build a credible public creator profile—the profile a brand will later review when deciding whether to approve a shop.

## Tasks

- [ ] Build profile header: avatar, display name, bio, and niche.
- [ ] Add platforms and self-reported audience-size section.
- [ ] Add example posts/content section.
- [ ] Add rating and completed-shops count.
- [ ] Design incomplete-profile and no-content empty states.
- [ ] Provide an Edit profile path to Settings.

## Components and later data

- Reuse/build: `CreatorProfileCard`, `EmptyState`
- shadcn: Avatar, Badge, Button, Skeleton
- Later data: `CreatorProfile`, `SocialAccount`, `Rating`

## Done when

The public profile is complete, responsive, and clearly reusable in future brand discovery and review surfaces.
